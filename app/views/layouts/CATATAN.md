# Folder view: layouts

PIC: Ringga Budi Utama (Project Lead, UI/UX, dan Frontend)

Salin potongan HTML dari `public/` ke folder ini saat backend mulai dipasang,
lalu ganti data statis menjadi variabel PHP. Contoh urutan:

1. Pindahkan bagian berulang (navbar, sidebar, topbar, footer) ke `layouts/`.
2. Ubah data dummy pada JavaScript menjadi data dari controller.
3. Sisakan JavaScript hanya untuk interaksi tampilan, bukan sumber data.
